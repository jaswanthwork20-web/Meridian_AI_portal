# Troubleshooting: invoice stuck in draft status

**Confluence URL:** https://agnishpaul2002.atlassian.net/wiki/spaces/SELFHELP/pages/1474580
**Page ID:** 1474580

## Content

Problem An invoice remains in Draft status and does not move to Submitted. Steps to resolve Check that all mandatory fields are filled in. Refresh the page and try submitting again. If the issue persists after a refresh, contact support with the invoice ID and a screenshot of any error shown.
