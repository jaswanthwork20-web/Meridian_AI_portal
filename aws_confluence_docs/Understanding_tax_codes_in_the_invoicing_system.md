# Understanding tax codes in the invoicing system

**Confluence URL:** https://agnishpaul2002.atlassian.net/wiki/spaces/SELFHELP/pages/1474564
**Page ID:** 1474564

## Content

Overview Tax codes determine how tax is calculated and reported for each invoice, based on GST (Goods and Services Tax) brackets. Current tax brackets GST 5%: Applies to select essential product categories. GST 12%: Applies to standard mid-tier products. GST 18%: The default rate for most catalog items. GST 28% (New Category): Used for newly onboarded product categories. Invoices using this bracket require Remarks explaining the classification, for audit purposes. If you're unsure which code to use Check the product's category listing, or raise a query with the Finance Configuration team.
