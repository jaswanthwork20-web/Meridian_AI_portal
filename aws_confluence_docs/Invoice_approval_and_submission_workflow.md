# Invoice approval and submission workflow

**Confluence URL:** https://agnishpaul2002.atlassian.net/wiki/spaces/SELFHELP/pages/1441820
**Page ID:** 1441820

## Content

Overview Once submitted, invoices go through the following stages: Draft, Submitted, Under Review, Approved. Steps Draft invoices can be edited freely. Once submitted, an invoice is locked and routed for review. If rejected, the invoice returns to Draft with reviewer comments.
